# Afinador PWA Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** PWA instalable para afinar guitarra (6/7/8) y bajo (4/5/6) por micrófono, con afinaciones propias compartibles por link/QR, sin backend.

**Architecture:** Lógica pura y testeable en `src/music/` (notas, afinaciones, matching, estado del afinador) y `src/audio/` (detección con pitchy, suavizado, motor de lectura); `src/state/` persiste en `localStorage` y codifica links; `src/ui/` (Preact) solo pinta y despacha eventos. El micrófono entra por un `AnalyserNode` que el motor lee cada 40 ms.

**Tech Stack:** Vite 8 · Preact 11 · TypeScript 6.0 · pitchy 4 · Vitest 5 · vite-plugin-pwa 2 · qrcode · ESLint 10 + typescript-eslint · Prettier · GitHub Pages.

**Spec:** `docs/superpowers/specs/2026-10-24-afinador-design.md` (leer entera antes de empezar; `afinador-spec.md` es el documento original, la spec manda donde difieren).

## Global Constraints

- Node 22 + npm. Repo `matiasArrebillaga/afinador`, rama `main`, Vite `base: '/afinador/'`.
- Dependencias permitidas, nada más sin preguntar: `preact`, `pitchy`, `qrcode`, `vite-plugin-pwa`; dev: `vite`, `@preact/preset-vite`, `@babel/core`, `typescript@~6.0`, `vitest`, `@vitejs/plugin-basic-ssl`, `eslint`, `@eslint/js`, `typescript-eslint`, `prettier`, `@types/qrcode`.
- TypeScript fijado en `~6.0`: `typescript-eslint` exige `<6.1`.
- Código e identificadores en inglés. Todo texto visible sale de `src/ui/strings.ts`, en español o inglés según `navigator.language` (fallback inglés). Texto mínimo: ícono + 1–3 palabras.
- `src/music/` y `src/audio/` nunca importan de `src/ui/`.
- Notas guardadas en notación inglesa (`E2`), de grave a aguda; frecuencias siempre calculadas.
- Constantes de la spec: La4 440 (415–466) · afinado entra ±3 cents, sale > ±5 · marca de cuerda ≥ 500 ms seguidos dentro de ±3 · retención 1000 ms · fuera de rango > 50 cents · clarity ≥ 0,9 · búsqueda 25–1200 Hz · rango del editor A0–D6 · nombres 1–40 caracteres · ventana 8192 (< 60 Hz) / 4096 (< 100 Hz o cromático) / 2048.
- Guitarra: 6, 7, 8 cuerdas. Bajo: 4, 5, 6.
- Solo tema oscuro. Fuente `ui-monospace, Menlo, Consolas, monospace`. Nunca `alert`/`confirm`/`prompt`.
- **Fin de cada fase = detenerse y confirmar con el autor** antes de seguir (tareas marcadas 🛑).
- **Decisiones tomadas al escribir el plan (el autor debe aprobarlas al revisar):**
  1. Captura con `AnalyserNode` en lugar de un `AudioWorklet` propio: misma señal, un archivo menos, sin cargar módulos de worklet. Si en el móvil se ven cortes de lectura, se cambia.
  2. Tonos de referencia en un botón ♪ dentro de la barra de modos (en modo ♪, tocar una cuerda la hace sonar); en modo MAN, tocar una cuerda la fija como objetivo.
  3. Junto a los Hz se muestra el desvío en cents con signo (`82.4 Hz · +12`).

## Review Focus

1. **Dos cuerdas a una octava** (DADGAD D3/D4, Open D D2/D3): el descarte de octava no debe trabar el cambio real de cuerda → test "acepta una octava real tras 3 lecturas" en Task 6.
2. **Afinación borrada o storage roto/bloqueado/de otra versión**: la app debe abrir con valores por defecto y Guitarra 6 Estándar → tests en Task 4 (`findTuning`) y Task 9 / Task 12 (storage).
3. **Cambio de guitarra a bajo con la app escuchando**: el motor debe leer la nueva ventana sin mezclar lecturas viejas → test "cambia el tamaño de ventana" en Task 7.
4. **El tono de referencia entra por el micrófono**: con el motor en pausa no debe salir ninguna lectura → test "pausa" en Task 7.
5. **Link compartido con nombre de 40 caracteres que ya existe**: el sufijo `(2)` no debe pasar de 40, o la afinación se descarta al recargar → test de `uniqueName` en Task 16.

```ts
export type NoteNaming = 'en' | 'es';

const PITCH_CLASSES = ['C', 'C#', 'D', 'D#', 'E', 'F', 'F#', 'G', 'G#', 'A', 'A#', 'B'];
const PITCH_CLASSES_ES = ['Do', 'Do#', 'Re', 'Re#', 'Mi', 'Fa', 'Fa#', 'Sol', 'Sol#', 'La', 'La#', 'Si'];

export const MIN_MIDI = 21; // A0
export const MAX_MIDI = 86; // D6
export const A4_DEFAULT = 440;
export const A4_MIN = 415;
export const A4_MAX = 466;

export function noteToMidi(note: string): number | null {
  const match = /^([A-G]#?)(\d)$/.exec(note);
  if (!match) return null;
  const pitchClass = PITCH_CLASSES.indexOf(match[1]);
  if (pitchClass < 0) return null;
  return (Number(match[2]) + 1) * 12 + pitchClass;
}

export function midiToNote(midi: number): string {
  return `${PITCH_CLASSES[((midi % 12) + 12) % 12]}${Math.floor(midi / 12) - 1}`;
}

export function midiToFreq(midi: number, a4 = A4_DEFAULT): number {
  return a4 * 2 ** ((midi - 69) / 12);
}

export function freqToMidi(freq: number, a4 = A4_DEFAULT): number {
  return 69 + 12 * Math.log2(freq / a4);
}

export function noteToFreq(note: string, a4 = A4_DEFAULT): number {
  const midi = noteToMidi(note);
  if (midi === null) throw new Error(`Invalid note: ${note}`);
  return midiToFreq(midi, a4);
}

export function cents(detected: number, target: number): number {
  return 1200 * Math.log2(detected / target);
}

export function displayNote(note: string, naming: NoteNaming): string {
  const midi = noteToMidi(note);
  if (naming === 'en' || midi === null) return note;
  return `${PITCH_CLASSES_ES[midi % 12]}${Math.floor(midi / 12) - 1}`;
}
```

```ts
import { MAX_MIDI, MIN_MIDI, noteToMidi } from './notes';

export type Instrument = 'guitar' | 'bass';

export const STRING_COUNTS: Record<Instrument, readonly number[]> = {
  guitar: [6, 7, 8],
  bass: [4, 5, 6],
};

export interface Tuning {
  id: string;
  name: string;
  instrument: Instrument;
  notes: string[]; // low → high
  builtIn: boolean;
}

function preset(instrument: Instrument, slug: string, name: string, notes: string): Tuning {
  const list = notes.split(' ');
  return { id: `${instrument}-${list.length}-${slug}`, name, instrument, notes: list, builtIn: true };
}
```

```ts
  index: number; // -1 in chromatic mode
  note: string;
  targetFreq: number;
  cents: number;
}

export const OUT_OF_RANGE_CENTS = 50;

export function matchIndex(
  freq: number,
  notes: readonly string[],
  index: number,
  a4: number,
): Match {
  const i = Math.max(0, Math.min(index, notes.length - 1));
  const targetFreq = noteToFreq(notes[i], a4);
  return { index: i, note: notes[i], targetFreq, cents: cents(freq, targetFreq) };
}

export function matchString(freq: number, notes: readonly string[], a4: number): Match {
  let best = matchIndex(freq, notes, 0, a4);
  for (let i = 1; i < notes.length; i++) {
    const candidate = matchIndex(freq, notes, i, a4);
    if (Math.abs(candidate.cents) < Math.abs(best.cents)) best = candidate;
  }
  return best;
}

export function matchChromatic(freq: number, a4: number): Match {
  const midi = Math.round(freqToMidi(freq, a4));
  const targetFreq = midiToFreq(midi, a4);
  return { index: -1, note: midiToNote(midi), targetFreq, cents: cents(freq, targetFreq) };
}
```

```ts
// harmonics[k] is the amplitude of harmonic k+1 (fundamental first).
export function tone(
  freq: number,
  size: number,
  sampleRate = 48000,
  harmonics: number[] = [1],
): Float32Array {
  const out = new Float32Array(size);
  for (let i = 0; i < size; i++) {
    let v = 0;
    harmonics.forEach((amp, k) => {
      v += amp * Math.sin((2 * Math.PI * freq * (k + 1) * i) / sampleRate);
    });
    out[i] = 0.3 * v;
  }
  return out;
}
```

```ts
import { PitchDetector } from 'pitchy';

export interface PitchReading {
  freq: number;
  clarity: number;
  rms: number;
}

export type Detect = (buf: Float32Array, sampleRate: number) => PitchReading;
export type WindowSize = 2048 | 4096 | 8192;

export const MIN_FREQ = 25;
export const MAX_FREQ = 1200;
export const MIN_CLARITY = 0.9;
export const DEFAULT_RMS_THRESHOLD = 0.01;

export function windowSizeFor(lowestFreq: number | null): WindowSize {
  if (lowestFreq === null) return 4096;
  if (lowestFreq < 60) return 8192;
  if (lowestFreq < 100) return 4096;
  return 2048;
}

export function rms(buf: Float32Array): number {
  let sum = 0;
  for (const v of buf) sum += v * v;
  return Math.sqrt(sum / buf.length);
}

export function createDetector(size: number): Detect {
  const detector = PitchDetector.forFloat32Array(size);
  return (buf, sampleRate) => {
    const [freq, clarity] = detector.findPitch(buf, sampleRate);
    return { freq, clarity, rms: rms(buf) };
  };
}

export function isUsable(r: PitchReading, rmsThreshold: number): boolean {
  return (
    r.rms >= rmsThreshold && r.clarity >= MIN_CLARITY && r.freq >= MIN_FREQ && r.freq <= MAX_FREQ
  );
}
```

```ts
import { cents } from '../music/notes';

export interface SmootherOptions {
  medianSize: number;
  emaAlpha: number;
  holdMs: number;
  octaveConfirmations: number;
}

const DEFAULTS: SmootherOptions = { medianSize: 5, emaAlpha: 0.3, holdMs: 1000, octaveConfirmations: 3 };
const NEW_NOTE_CENTS = 100;
const OCTAVE_TOLERANCE_CENTS = 50;

export function median(xs: readonly number[]): number {
  const sorted = [...xs].sort((a, b) => a - b);
  const mid = sorted.length >> 1;
  return sorted.length % 2 ? sorted[mid] : (sorted[mid - 1] + sorted[mid]) / 2;
}

function isOctaveJump(freq: number, ref: number): boolean {
  return Math.abs(Math.abs(cents(freq, ref)) - 1200) <= OCTAVE_TOLERANCE_CENTS;
}

export class Smoother {
  private history: number[] = [];
  private value: number | null = null;
  private lastAt = -Infinity;
  private octaveStreak = 0;

  constructor(private readonly opts: SmootherOptions = DEFAULTS) {}

  push(freq: number, now: number): number {
    if (this.current(now) === null) this.reset();
    this.lastAt = now;

    if (this.value !== null && isOctaveJump(freq, this.value)) {
      this.octaveStreak++;
      if (this.octaveStreak < this.opts.octaveConfirmations) return this.value;
      this.reset();
    }
    this.octaveStreak = 0;

    this.history.push(freq);
    if (this.history.length > this.opts.medianSize) this.history.shift();
    const m = median(this.history);

    if (this.value === null || Math.abs(cents(m, this.value)) > NEW_NOTE_CENTS) this.value = m;
    else this.value += this.opts.emaAlpha * (m - this.value);
    return this.value;
  }

  current(now: number): number | null {
    if (this.value !== null && now - this.lastAt > this.opts.holdMs) this.reset();
    return this.value;
  }

  reset(): void {
    this.history = [];
    this.value = null;
    this.octaveStreak = 0;
  }
}
```

```ts
import {
  DEFAULT_RMS_THRESHOLD,
  createDetector,
  isUsable,
  type Detect,
  type PitchReading,
  type WindowSize,
} from './pitch';
import { Smoother } from './smoothing';

export interface AudioSource {
  sampleRate: number;
  read(size: number): Float32Array;
}

export interface EngineFrame {
  raw: PitchReading;
  freq: number | null; // smoothed; null = idle
  windowSize: number;
  sampleRate: number;
}

export const FRAME_MS = 40;

export class Engine {
  rmsThreshold = DEFAULT_RMS_THRESHOLD;
  private detect: Detect;
  private smoother = new Smoother();
  private timer: ReturnType<typeof setInterval> | undefined;
  private paused = false;

  constructor(
    private readonly source: AudioSource,
    private readonly onFrame: (frame: EngineFrame) => void,
    private size: WindowSize = 2048,
    private readonly now: () => number = () => performance.now(),
  ) {
    this.detect = createDetector(size);
  }

  start(): void {
    this.timer ??= setInterval(() => this.tick(), FRAME_MS);
  }

  stop(): void {
    clearInterval(this.timer);
    this.timer = undefined;
  }

  setWindowSize(size: WindowSize): void {
    if (size === this.size) return;
    this.size = size;
    this.detect = createDetector(size);
    this.smoother.reset();
  }

  pause(): void {
    this.paused = true;
    this.smoother.reset();
  }

  resume(): void {
    this.paused = false;
  }

  tick(): void {
    if (this.paused) return;
    const raw = this.detect(this.source.read(this.size), this.source.sampleRate);
    const t = this.now();
    const freq = isUsable(raw, this.rmsThreshold)
      ? this.smoother.push(raw.freq, t)
      : this.smoother.current(t);
    this.onFrame({ raw, freq, windowSize: this.size, sampleRate: this.source.sampleRate });
  }
}
```

```ts
import type { AudioSource } from './engine';

export type MicErrorKind = 'denied' | 'no-mic' | 'insecure' | 'unknown';

export class MicError extends Error {
  constructor(readonly kind: MicErrorKind) {
    super(kind);
  }
}

export interface Mic extends AudioSource {
  context: AudioContext;
  close(): Promise<void>;
}

const MAX_WINDOW = 8192;

function errorKind(e: unknown): MicErrorKind {
  const name = e instanceof DOMException ? e.name : '';
  if (name === 'NotAllowedError' || name === 'SecurityError') return 'denied';
  if (name === 'NotFoundError' || name === 'OverconstrainedError') return 'no-mic';
  return 'unknown';
}

// Call synchronously from a click handler: iOS only unlocks audio for an AudioContext
// created during a user gesture.
export async function startMic(): Promise<Mic> {
  if (!window.isSecureContext || !navigator.mediaDevices?.getUserMedia) {
    throw new MicError('insecure');
  }
  const context = new AudioContext();
  let stream: MediaStream;
  try {
    stream = await navigator.mediaDevices.getUserMedia({
      audio: { echoCancellation: false, noiseSuppression: false, autoGainControl: false },
    });
  } catch (e) {
    await context.close();
    throw new MicError(errorKind(e));
  }
  await context.resume();

  const analyser = context.createAnalyser();
  analyser.fftSize = MAX_WINDOW;
  analyser.smoothingTimeConstant = 0;
  context.createMediaStreamSource(stream).connect(analyser);
  const buffer = new Float32Array(MAX_WINDOW);

  return {
    context,
    sampleRate: context.sampleRate,
    read(size) {
      analyser.getFloatTimeDomainData(buffer);
      return buffer.subarray(MAX_WINDOW - size); // most recent `size` samples
    },
    async close() {
      stream.getTracks().forEach((t) => t.stop());
      await context.close();
    },
  };
}
```

```ts
import { OUT_OF_RANGE_CENTS, matchChromatic, matchIndex, matchString, type Match } from './matcher';

export type Mode = 'auto' | 'manual' | 'chromatic';

export interface TunerConfig {
  notes: readonly string[];
  a4: number;
  mode: Mode;
  manualIndex: number;
  thresholdCents: number;
}

export interface TunerView {
  freq: number;
  note: string;
  cents: number;
  stringIndex: number; // -1 in chromatic mode
  outOfRange: boolean;
  inTune: boolean;
}

export const EXIT_EXTRA_CENTS = 2;
export const CONFIRM_MS = 500;

export class Tuner {
  readonly confirmed = new Set<number>();
  private inTune = false;
  private strictSince: number | null = null;
  private lastIndex: number | null = null;

  constructor(private config: TunerConfig) {}

  configure(config: TunerConfig): void {
    if (config.notes.join(' ') !== this.config.notes.join(' ')) this.confirmed.clear();
    this.config = config;
    this.resetTracking();
  }

  update(freq: number | null, now: number): TunerView | null {
    if (freq === null) {
      this.resetTracking();
      return null;
    }
    const match = this.match(freq);
    if (match.index !== this.lastIndex) {
      this.resetTracking();
      this.lastIndex = match.index;
    }

    const abs = Math.abs(match.cents);
    const { thresholdCents, a4 } = this.config;
    if (abs <= thresholdCents) {
      this.inTune = true;
      this.strictSince ??= now;
    } else {
      this.strictSince = null;
      if (abs > thresholdCents + EXIT_EXTRA_CENTS) this.inTune = false;
    }
    if (match.index >= 0 && this.strictSince !== null && now - this.strictSince >= CONFIRM_MS) {
      this.confirmed.add(match.index);
    }

    const outOfRange = abs > OUT_OF_RANGE_CENTS;
    return {
      freq,
      note: outOfRange ? matchChromatic(freq, a4).note : match.note,
      cents: match.cents,
      stringIndex: match.index,
      outOfRange,
      inTune: this.inTune,
    };
  }

  private match(freq: number): Match {
    const { notes, a4, mode, manualIndex } = this.config;
    if (mode === 'chromatic') return matchChromatic(freq, a4);
    if (mode === 'manual') return matchIndex(freq, notes, manualIndex, a4);
    return matchString(freq, notes, a4);
  }

  private resetTracking(): void {
    this.inTune = false;
    this.strictSince = null;
    this.lastIndex = null;
  }
}
```

```ts
import { A4_DEFAULT, A4_MAX, A4_MIN, type NoteNaming } from '../music/notes';
import type { Mode } from '../music/tuner';
import { DEFAULT_TUNING_ID } from '../music/tunings';

export interface Settings {
  a4: number;
  activeTuningId: string;
  mode: Mode;
  inTuneThresholdCents: number;
  noteNaming: NoteNaming;
}

export const DEFAULT_SETTINGS: Settings = {
  a4: A4_DEFAULT,
  activeTuningId: DEFAULT_TUNING_ID,
  mode: 'auto',
  inTuneThresholdCents: 3,
  noteNaming: 'en',
};

const VERSION = 1;
const SETTINGS_KEY = 'afinador:settings';

function read(key: string): unknown {
  try {
    const raw = localStorage.getItem(key);
    if (!raw) return null;
    const parsed = JSON.parse(raw);
    return parsed?.version === VERSION ? parsed.data : null;
  } catch {
    return null;
  }
}

function write(key: string, data: unknown): void {
  try {
    localStorage.setItem(key, JSON.stringify({ version: VERSION, data }));
  } catch {
    // Blocked or full storage: the app keeps working with in-memory state.
  }
}

function sanitizeSettings(d: Record<string, unknown>): Settings {
  const s = { ...DEFAULT_SETTINGS };
  if (typeof d.a4 === 'number' && d.a4 >= A4_MIN && d.a4 <= A4_MAX) s.a4 = d.a4;
  if (typeof d.activeTuningId === 'string') s.activeTuningId = d.activeTuningId;
  if (d.mode === 'auto' || d.mode === 'manual' || d.mode === 'chromatic') s.mode = d.mode;
  if (typeof d.inTuneThresholdCents === 'number' && d.inTuneThresholdCents > 0 && d.inTuneThresholdCents <= 10) {
    s.inTuneThresholdCents = d.inTuneThresholdCents;
  }
  if (d.noteNaming === 'en' || d.noteNaming === 'es') s.noteNaming = d.noteNaming;
  return s;
}

export function loadSettings(): Settings {
  const d = read(SETTINGS_KEY);
  return d && typeof d === 'object' ? sanitizeSettings(d as Record<string, unknown>) : { ...DEFAULT_SETTINGS };
}

export function saveSettings(s: Settings): void {
  write(SETTINGS_KEY, s);
}
```

```ts
  settings: Settings,
  manualIndex: number,
) {
  const [frame, setFrame] = useState<EngineFrame | null>(null);
  const [view, setView] = useState<TunerView | null>(null);
  const tuner = useMemo(() => new Tuner(tunerConfig(tuning, settings, manualIndex)), []);
  const engine = useRef<Engine | null>(null);

  useEffect(() => {
    tuner.configure(tunerConfig(tuning, settings, manualIndex));
    engine.current?.setWindowSize(windowFor(tuning, settings));
  }, [tuning, settings, manualIndex]);

  useEffect(() => {
    if (!mic) return;
    const e = new Engine(
      mic,
      (f) => {
        setFrame(f);
        setView(tuner.update(f.freq, performance.now()));
      },
      windowFor(tuning, settings),
    );
    engine.current = e;
    e.start();
    return () => {
      e.stop();
      engine.current = null;
    };
  }, [mic]);

  return { frame, view, confirmed: tuner.confirmed as ReadonlySet<number>, engine };
}
```

```tsx
const RANGE = 50;
const TICKS = Array.from({ length: 21 }, (_, i) => i * 5 - RANGE);
const LABELS = [-50, -25, 0, 25, 50];
// Hue stops by |cents|: green when in tune, amber mid-way, red far off.
const HUE_STOPS: readonly [number, number][] = [
  [3, 145],
  [15, 40],
  [35, 6],
];

export function meterHue(absCents: number): number {
  if (absCents <= HUE_STOPS[0][0]) return HUE_STOPS[0][1];
  for (let i = 1; i < HUE_STOPS.length; i++) {
    const [a0, h0] = HUE_STOPS[i - 1];
    const [a1, h1] = HUE_STOPS[i];
    if (absCents <= a1) return h0 + ((h1 - h0) * (absCents - a0)) / (a1 - a0);
  }
  return HUE_STOPS[HUE_STOPS.length - 1][1];
}

export function meterColor(cents: number | null, outOfRange: boolean): string {
  if (cents === null) return 'var(--fg)';
  if (outOfRange) return 'var(--far)';
  const abs = Math.abs(cents);
  return `hsl(${meterHue(abs).toFixed(0)} ${abs <= HUE_STOPS[0][0] ? 70 : 90}% 62%)`;
}

const tickHeight = (c: number) => (c === 0 ? 100 : c % 25 === 0 ? 55 : c % 10 === 0 ? 38 : 22);

export function Meter({ cents }: { cents: number | null }) {
  const clamped = cents === null ? 0 : Math.max(-RANGE, Math.min(RANGE, cents));
  return (
    <div
      class="meter"
      role="meter"
      aria-valuemin={-RANGE}
      aria-valuemax={RANGE}
      aria-valuenow={clamped}
    >
      <div class="zone" />
      <div class="band" />
      <div class="ticks">
        {TICKS.map((c) => (
          <i
            key={c}
            class={c === 0 ? 'zero' : c % 25 === 0 ? 'major' : undefined}
            style={{ left: `${c + RANGE}%`, height: `${tickHeight(c)}%` }}
          />
        ))}
      </div>
      <div class="track">
        <div
          class={cents === null ? 'needle idle' : 'needle'}
          style={{ transform: `translateX(${clamped + RANGE}%)` }}
        />
      </div>
      <div class="labels">
        {LABELS.map((c) => (
          <span key={c} style={{ left: `${c + RANGE}%` }}>
            {c > 0 ? `+${c}` : c < 0 ? `−${-c}` : '0'}
          </span>
        ))}
      </div>
    </div>
  );
}
```

```tsx
import { useRef, useState } from 'preact/hooks';
import { MicError, startMic, type Mic, type MicErrorKind } from './audio/mic';
import { BUILT_IN_TUNINGS, findTuning } from './music/tunings';
import { loadSettings, saveSettings, type Settings } from './state/storage';
import { DebugScreen } from './ui/screens/DebugScreen';
import { StartScreen } from './ui/screens/StartScreen';
import { TunerScreen } from './ui/screens/TunerScreen';
import { TuningPicker } from './ui/screens/TuningPicker';
import { useTunerEngine } from './ui/use-tuner';

type Screen = 'tuner' | 'picker' | 'debug';

export function App() {
  const [settings, setSettings] = useState(loadSettings);
  const [mic, setMic] = useState<Mic | null>(null);
  const [micError, setMicError] = useState<MicErrorKind | null>(null);
  const [suspended, setSuspended] = useState(false);
  const [screen, setScreen] = useState<Screen>('tuner');
  const taps = useRef({ count: 0, at: 0 });

  const tunings = BUILT_IN_TUNINGS;
  const tuning = findTuning(tunings, settings.activeTuningId);
  const { frame, view, confirmed, engine } = useTunerEngine(mic, tuning, settings, 0);

  function updateSettings(patch: Partial<Settings>) {
    setSettings((s) => {
      const next = { ...s, ...patch };
      saveSettings(next);
      return next;
    });
  }

  async function start() {
    try {
      const m = await startMic();
      m.context.onstatechange = () => setSuspended(m.context.state !== 'running');
      setMic(m);
    } catch (e) {
      setMicError(e instanceof MicError ? e.kind : 'unknown');
    }
  }

  function onTitleTap() {
    const now = Date.now();
    const t = taps.current;
    t.count = now - t.at < 600 ? t.count + 1 : 1;
    t.at = now;
    if (t.count >= 5) {
      t.count = 0;
      setScreen('debug');
    }
  }

  if (!mic) return <StartScreen error={micError} onStart={start} />;

  if (screen === 'debug') {
    return <DebugScreen frame={frame} engine={engine.current} onClose={() => setScreen('tuner')} />;
  }
  if (screen === 'picker') {
    return (
      <TuningPicker
        tunings={tunings}
        activeId={tuning.id}
        naming={settings.noteNaming}
        onSelect={(id) => {
          updateSettings({ activeTuningId: id });
          setScreen('tuner');
        }}
        onClose={() => setScreen('tuner')}
      />
    );
  }
  return (
    <TunerScreen
      view={view}
      tuning={tuning}
      naming={settings.noteNaming}
      confirmed={confirmed}
      suspended={suspended}
      onResume={() => void mic.context.resume()}
      onOpenPicker={() => setScreen('picker')}
      onTitleTap={onTitleTap}
    />
  );
}
```

```ts
import { MAX_MIDI, MIN_MIDI, midiToNote, noteToMidi } from './notes';
import { standardFor, type Instrument, type Tuning } from './tunings';

export function shiftNote(note: string, semitones: number): string {
  const midi = noteToMidi(note);
  if (midi === null) return note;
  const next = midi + semitones;
  return next < MIN_MIDI || next > MAX_MIDI ? note : midiToNote(next);
}

export function copyTuning(base: Tuning, name: string): Tuning {
  return {
    id: crypto.randomUUID(),
    name,
    instrument: base.instrument,
    notes: [...base.notes],
    builtIn: false,
  };
}

export function blankTuning(instrument: Instrument, strings: number, name: string): Tuning {
  return copyTuning(standardFor(instrument, strings), name);
}
```

```ts
const TUNINGS_KEY = 'afinador:tunings';

function isStoredTuning(t: unknown): t is Tuning {
  if (!t || typeof t !== 'object') return false;
  const r = t as Record<string, unknown>;
  return (
    typeof r.id === 'string' &&
    typeof r.name === 'string' &&
    isValidName(r.name) &&
    isValidTuningShape(r.instrument, r.notes)
  );
}

export function loadTunings(): Tuning[] {
  const d = read(TUNINGS_KEY);
  if (!Array.isArray(d)) return [];
  return d.filter(isStoredTuning).map((t) => ({
    id: t.id,
    name: t.name,
    instrument: t.instrument,
    notes: [...t.notes],
    builtIn: false,
  }));
}

export function saveTunings(tunings: readonly Tuning[]): void {
  write(TUNINGS_KEY, tunings);
```

```ts
export const TONE_MS = 2000;
const FADE_S = 0.05;
const RELEASE_S = 0.3;
const LEVEL = 0.3;

// Triangle wave: audible on phone speakers, unlike a pure sine at low pitches.
export function playTone(context: AudioContext, freq: number, onEnd: () => void): () => void {
  const osc = context.createOscillator();
  const gain = context.createGain();
  const start = context.currentTime;
  const end = start + TONE_MS / 1000;

  osc.type = 'triangle';
  osc.frequency.value = freq;
  gain.gain.setValueAtTime(0, start);
  gain.gain.linearRampToValueAtTime(LEVEL, start + FADE_S);
  gain.gain.setValueAtTime(LEVEL, end - RELEASE_S);
  gain.gain.linearRampToValueAtTime(0, end);
  osc.connect(gain).connect(context.destination);
  osc.onended = onEnd;
  osc.start(start);
  osc.stop(end);

  return () => {
    const now = context.currentTime;
    gain.gain.cancelScheduledValues(now);
    gain.gain.setValueAtTime(gain.gain.value, now);
    gain.gain.linearRampToValueAtTime(0, now + FADE_S);
    osc.stop(now + FADE_S);
  };
}
```

```ts
import { MAX_NAME, isValidName, isValidTuningShape, type Instrument } from '../music/tunings';

export interface SharedTuning {
  name: string;
  instrument: Instrument;
  notes: string[];
}

const MAX_CODE_LENGTH = 2000;

export function encodeTuning(t: SharedTuning): string {
  const json = JSON.stringify({ n: t.name, i: t.instrument === 'guitar' ? 'g' : 'b', s: t.notes });
  let binary = '';
  for (const byte of new TextEncoder().encode(json)) binary += String.fromCharCode(byte);
  return btoa(binary).replace(/\+/g, '-').replace(/\//g, '_').replace(/=+$/, '');
}

export function decodeTuning(code: string): SharedTuning | null {
  if (code.length > MAX_CODE_LENGTH) return null;
  try {
    const binary = atob(code.replace(/-/g, '+').replace(/_/g, '/'));
    const bytes = Uint8Array.from(binary, (c) => c.charCodeAt(0));
    const raw = JSON.parse(new TextDecoder('utf-8', { fatal: true }).decode(bytes));
    const instrument = raw?.i === 'g' ? 'guitar' : raw?.i === 'b' ? 'bass' : null;
    const name = typeof raw?.n === 'string' ? raw.n.trim() : '';
    if (!instrument || !isValidName(name) || !isValidTuningShape(instrument, raw.s)) return null;
    return { name, instrument, notes: [...raw.s] };
  } catch {
    return null;
  }
}

export function shareLink(t: SharedTuning, pageUrl: string): string {
  return `${pageUrl.split('#')[0]}#t=${encodeTuning(t)}`;
}

export function readShareHash(hash: string): SharedTuning | null | undefined {
  const match = /^#t=(.*)$/.exec(hash);
  return match ? decodeTuning(match[1]) : undefined;
}

export function uniqueName(name: string, existing: readonly string[]): string {
  if (!existing.includes(name)) return name;
  for (let i = 2; ; i++) {
    const suffix = ` (${i})`;
    const candidate = name.slice(0, MAX_NAME - suffix.length).trimEnd() + suffix;
    if (!existing.includes(candidate)) return candidate;
  }
}
```

```js
// ponytail: provisional icon drawn from rectangles (the meter); replace when the real icon exists.
import { mkdirSync, writeFileSync } from 'node:fs';
import { Buffer } from 'node:buffer';
import { crc32, deflateSync } from 'node:zlib';

const WHITE = [255, 255, 255];
const GREEN = [0, 255, 102];

function draw(size, pad) {
  const px = Buffer.alloc(size * size * 3); // black
  const fill = (x0, y0, w, h, [r, g, b]) => {
    for (let y = y0; y < y0 + h; y++) {
      for (let x = x0; x < x0 + w; x++) {
        const i = (y * size + x) * 3;
        px[i] = r;
        px[i + 1] = g;
        px[i + 2] = b;
      }
    }
  };
  const unit = (size - 2 * pad) / 16;
  for (let k = 0; k < 7; k++) {
    const x = Math.round(pad + unit * (1.4 + k * 2));
    fill(x, Math.round(pad + unit * 5), Math.round(unit * 1.2), Math.round(unit * 6), k === 3 ? GREEN : WHITE);
  }
  return px;
}

function png(size, pad) {
  const px = draw(size, pad);
  const raw = Buffer.alloc((size * 3 + 1) * size);
  for (let y = 0; y < size; y++) px.copy(raw, y * (size * 3 + 1) + 1, y * size * 3, (y + 1) * size * 3);
  const chunk = (type, data) => {
    const len = Buffer.alloc(4);
    len.writeUInt32BE(data.length);
    const body = Buffer.concat([Buffer.from(type), data]);
    const crc = Buffer.alloc(4);
    crc.writeUInt32BE(crc32(body));
    return Buffer.concat([len, body, crc]);
  };
  const ihdr = Buffer.alloc(13);
  ihdr.writeUInt32BE(size, 0);
  ihdr.writeUInt32BE(size, 4);
  ihdr[8] = 8; // bit depth
  ihdr[9] = 2; // RGB
  return Buffer.concat([
    Buffer.from([137, 80, 78, 71, 13, 10, 26, 10]),
    chunk('IHDR', ihdr),
    chunk('IDAT', deflateSync(raw)),
    chunk('IEND', Buffer.alloc(0)),
  ]);
}

const svg = `<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 16 16"><rect width="16" height="16" fill="#000"/>${[0, 1, 2, 3, 4, 5, 6]
  .map((k) => `<rect x="${1.4 + k * 2}" y="5" width="1.2" height="6" fill="${k === 3 ? '#00ff66' : '#fff'}"/>`)
  .join('')}</svg>`;

mkdirSync('public/icons', { recursive: true });
writeFileSync('public/icons/icon-192.png', png(192, 12));
writeFileSync('public/icons/icon-512.png', png(512, 32));
writeFileSync('public/icons/icon-maskable-512.png', png(512, 104)); // 80 % safe zone
writeFileSync('public/icons/icon.svg', svg);
```
